Custom input sequences

Separate steps with commas. Use + for simultaneous buttons, :frames for a hold, and N for a release/wait. F/B mean forward/back. Example: LP, N, LP, F, LK, HP. The release between LP presses makes them separate taps. Edit the timing for your move.

0 starts immediately on the first emulated frame. 5 explores waits of 0–5 frames before the first input, independently of delays between moves.

If the dummy starts in hitstun, Require a true combo also rejects recovery before your first new hit. Damage counts only what the continuation adds after loading.

Try delays between moves and around landing, then refine frame by frame within the trial budget.

Includes waiting for air-to-ground follow-ups. Turn automatic timing off to use only the explicit delay list.
